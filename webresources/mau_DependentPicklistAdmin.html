About Dependent Picklists

This app helps you control which choices users see in one dropdown based on what they pick in another dropdown — without writing any code.

Why use it?

Sometimes only a few options make sense together. Showing every option for every situation creates noise and bad data. With dependent picklists, the second dropdown automatically shows only the choices that fit the first one.

Example: On a Case form, when the user picks Origin = Phone, you only want to allow Type = Question or Problem. When they pick Origin = Email, you want different options. This app lets you set that up in a few clicks.

How it works

  1. Pick a table (for example, Case).
  2. Pick the controlling field — the dropdown the user chooses from first.
  3. Pick the dependent field — the dropdown that should change based on the first.
  4. Check the boxes in the matrix to say which combinations are allowed.
  5. Pick the forms where this should run, then click Save.

Good to know

If you leave a row completely empty, that means no dependent options are allowed when the user picks that controlling value — the dependent dropdown will be blocked.

The colors you see on dropdown options come from the colors admins configured in Power Platform's choice editor — so the form looks consistent with the rest of your app.
